# The text engine is GPL-3.0-or-later, not LGPL

`libtessera-engine` is meant to be adopted by other keyboards, which usually argues for LGPL. We keep it GPL-3.0-or-later like the rest of Tessera: the keyboards we expect to adopt it (Squeekboard, Stevia, Plasma Keyboard) are GPL-compatible, Maliit (the LGPL candidate) is being phased out, and GPL lets the engine take Squeekboard-derived code freely. Once GPL-only code lands in the engine, relicensing to LGPL is effectively impossible.
